📐 Panduan & Standar Kalibrasi Kualitas Struktur Kode (Harian + Riset)

  • NCLOC Adaptif per Bahasa: Baris kode aktif tanpa komentar/baris kosong. Batas sehat: ≤ 300 NCLOC untuk Backend/Logic (.php, .py, .ts, .go, .rs) dan ≤ 450 NCLOC untuk komponen UI deklaratif (.tsx, .jsx). Gunakan --strict untuk batas seragam 300 NCLOC.
  • Control-Flow Deep Nesting: Mengukur kedalaman percabangan/perulangan murni (if, for, foreach, while, switch, try) di dalam fungsi (≥ 4 level), tanpa menghitung kurung kurawal markup JSX.
  • CCN & Maintainability Index (MI): Rata-rata CCN sehat ≤ 15; MI Grade A (≥ 70), Grade B (55 – 69), Grade C (< 55).
