Tentang GreenCode Profiler

GreenCode Profiler adalah framework open-source yang dirancang untuk mengukur efisiensi energi perangkat lunak (*Green Software Engineering*) dengan mengisolasi proses aplikasi secara presisi.

Berbeda dari alat ukur tingkat mesin konvensional (seperti CodeCarbon) yang rentan terhadap gangguan socket jaringan dan proses sistem operasi lain, GreenCode Profiler hanya menghitung waktu CPU aktif murni ($t_{\text{user}} + t_{\text{system}}$) serta penggunaan memori fisik (RSS) dari proses target.

Fitur Utama

Kebal Bias Jaringan (I/O Wait)

Hanya mencatat waktu CPU saat memproses instruksi. Saat server menunggu paket database atau jaringan, waktu CPU bernilai 0 sehingga nilai Joule tidak membengkak semu.

Atribusi Granular Per-Endpoint

Mengisolasi pengukuran energi untuk setiap endpoint HTTP secara spesifik, sehingga developer dapat langsung menemukan fungsi mana yang menjadi *energy hotspot*.

Built-in Code Quality Analyzer

Menganalisis Cyclomatic Complexity (CCN), Maintainability Index, NCLOC, dan mendeteksi arsitektur buruk (*God Class, Fat Controller, Deep Nesting*) secara instan.

Language-Agnostic

Mendukung PHP (Laravel), Node.js (Next.js/Express), Python (FastAPI/Django), dan Go (Gin/Fiber) tanpa perlu mengubah kode aplikasi target.

Instalasi & Penggunaan

Pilih ekosistem bahasa pemrograman yang Anda gunakan:

Penggunaan di ekosistem Node.js / TypeScript:

# 1. Jalankan langsung via npx (tanpa install):
npx greencode-profiler run

# Atau install secara global:
npm install -g greencode-profiler
greencode run

Instalasi melalui pip:

# 1. Install package
pip install greencode-profiler

# 2. Jalankan profiling dari file greencode.json
greencode run

Penggunaan di project PHP / Laravel:

# 1. Install via Composer
composer require --dev greencode/profiler

# 2. Jalankan profiling
vendor/bin/greencode run

Penggunaan di project Go:

# 1. Install CLI binary
go install github.com/greencode-org/greencode@latest

# 2. Jalankan profiling
greencode run

Konfigurasi (greencode.json)

Profiling dikonfigurasi melalui berkas greencode.json sederhana di direktori root aplikasi:

{
  "project_name": "My Web Application",
  "runtime": "php",
  "source_dir": "app",
  "base_url": "http://127.0.0.1:8000",
  "repeats": 5,
  "cpu_tdp_watts": 15.0,
  "auth": {
    "type": "bearer",
    "token": "optional-token"
  },
  "endpoints": [
    { "path": "/api/users", "name": "List Users", "method": "GET" },
    { "path": "/api/reports/export", "name": "Export Document", "method": "GET" }
  ]
}

Referensi Perintah CLI

Perintah disusun berurutan sesuai alur kerja penggunaan:

Perintah Fungsi Contoh Penggunaan
greencode init Membuat file konfigurasi starter greencode.json otomatis sesuai bahasa project. greencode init --preset php
greencode run Menjalankan profiling lengkap (analisis struktur kode + konsumsi energi) dan membuka dashboard HTML. greencode run
greencode analyze Menganalisis kualitas struktur kode statis saja (CCN, NCLOC, Maintainability Index, dan Code Smells). greencode analyze ./src
greencode detect Mendiagnosa dan menampilkan proses server yang sedang aktif mendengarkan port. greencode detect
greencode ui Membuka kembali dashboard laporan HTML hasil profiling terakhir di web browser. greencode ui
greencode help Menampilkan panduan bantuan semua perintah atau perintah spesifik. greencode help run

Perbandingan Teknis

Dasar Waktu Wall-Clock Time (Jam Dinding) CPU Active Time ($t_{\text{user}} + t_{\text{sys}}$)

Granularitas 1 angka total agregat mesin Granular per-endpoint & per-modul
Analisis Kualitas Kode Tidak ada Built-in (CCN, LOC, Smells)
