Universal Energy & Code Quality Profiler

Framework audit efisiensi energi komputasi (Joule & kWh), kualitas kode statis, dan audit PHP Extension Optimization untuk web app modern (Next.js, Laravel, FastAPI, Express, Go, Rust).

Cara Pakai ↓ Unduh ZIP (v1.8.1)

Pilihan Penggunaan

Tersedia dua opsi yang dapat dipilih sesuai kebutuhan lingkungan Anda:

Syarat: Bebas dependensi (tidak butuh Node.js, Python, maupun Rust). Cukup Windows 64-bit.

# 1. Unduh dan ekstrak file GreenCode-v1.7.3-windows-x64.zip dari GitHub Releases
# 2. Salin file 'greencode.exe' ke root folder project Anda
# 3. Pastikan server aplikasi berjalan (misal: port 3000 / 8000)
# 4. Buka terminal di folder project, lalu jalankan:

.\greencode.exe init
.\greencode.exe run

Syarat: Memerlukan Node.js.

# 1. Jalankan perintah instalasi global via npm:
npm install -g git+https://github.com/Haekalss/GreenCode-Profiler.git

# 2. Masuk ke folder project manapun, lalu langsung jalankan:
greencode init
greencode run

Syarat: Memerlukan Python (pip).

# 1. Jalankan perintah instalasi via pip:
pip install git+https://github.com/Haekalss/GreenCode-Profiler.git

# 2. Perintah greencode langsung tersedia di terminal:
greencode init
greencode run

Syarat: Memerlukan PHP & Composer di project Anda.

# 1. Tambahkan ke composer dev dependencies:
composer require --dev greencode/profiler

# 2. Jalankan binary runner dari vendor:
./vendor/bin/greencode init
./vendor/bin/greencode run

Syarat: Memerlukan Go compiler.

# 1. Install CLI launcher ke GOPATH/bin:
go install github.com/Haekalss/GreenCode-Profiler/cmd/greencode@latest

# 2. Jalankan perintah:
greencode init
greencode run

Fitur Utama

Pengukuran Energi Murni

Menghitung konsumsi energi riil dalam satuan Joule dan kWh berbasis waktu CPU aktif, tanpa bias antrean jaringan (I/O wait).

Audit Kualitas Kode

Menganalisis Cyclomatic Complexity (CCN), Maintainability Index (MI), NCLOC, dan mendeteksi pola kode buruk (Code Smells).

Atribusi Granular Per-Rute

Mengidentifikasi secara spesifik endpoint atau halaman mana yang paling boros daya dan membebani komputasi server.

100% Rust Native

Eksekusi sangat cepat, hemat memori (<15 MB), dan tidak membebani mesin pengujian saat profiling berjalan.

Deteksi Rute Lintas Bahasa

Membaca seluruh rute aplikasi tanpa batas jumlah, termasuk rute bersarang dan prefix group, untuk Node.js, PHP, Python, Go, dan Rust.

Laporan Teragregasi per Endpoint

Setiap endpoint ditampilkan dalam satu baris berisi rata-rata dari seluruh pengulangan pengukuran, sehingga laporan tidak berulang.

Referensi Perintah CLI

Perintah Fungsi Contoh
greencode init Membuat file konfigurasi greencode.json dan auto-detect rute aplikasi. greencode init
greencode run Menjalankan audit lengkap (energi + kualitas kode) & menampilkan laporan HTML. greencode run
greencode analyze Menganalisis kualitas struktur kode statis saja (CCN, MI, Smells). greencode analyze
greencode routes Memindai seluruh rute nyata dari kode sumber aplikasi (semua bahasa). greencode routes [dir] [--limit N] [--filter K] [--exclude K]
greencode detect Mendiagnosis proses web server yang sedang aktif pada port lokal. greencode detect
greencode ui Membuka kembali dashboard laporan HTML hasil pengujian terakhir di browser. greencode ui
